## Key Implementation Details

- Pools are `DynamicSupervisor` with `maxChildren`, plus a DB-backed `QueueProducer`, because libeam's GenStage Producer only emits inside `handleDemand` and has no push API.
- libeam ZeroMQ transport assumes a peer's pub port is `rpc + 1`; cue keeps the default adjacent ports (rpc, rpc+1, rpc+2) and doesn't allow custom pub ports.
- Process isolation offers `systemd-scope` and `process-group`; `systemd-run --user --scope` isn't available without a user session, so tests use process groups.
